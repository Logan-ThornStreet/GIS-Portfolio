# Logan Bowdish — Spatial Analysis & GIS Explorer

A responsive, static portfolio website for GIS work products. It uses plain HTML, CSS, and JavaScript, so it can be hosted on GitHub Pages without a build step.

Two supplied topographic images are used as temporary visuals for selected work and as subtle site backgrounds. Replace these placeholders with project maps as your portfolio develops. Both files are in `assets/topography/`.

## Personalize before publishing

Search `index.html` for any remaining starter content and replace it with your own:

- City, professional background, and any details you want to personalize
- The Selected work section is intentionally marked with prompts. Add real project titles, project types, dates, summaries, methods, data, results, and maps when ready.

The two Selected work cards are placeholders. Replace their topo images and labels with your own project work when ready.

## Preview locally

Open `index.html` in a browser. No package installation or compilation is needed.

## Publish with GitHub Pages

1. Create a GitHub repository and push these files to its default branch.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the default branch and the `/ (root)` folder, then save.

GitHub Pages will publish the site at the URL shown in the Pages settings. This project has no build step; `index.html` should remain in the published root.
